# Apoie o Audio Cleaner 💚

O Audio Cleaner é gratuito e de código aberto. O apoio da comunidade ajuda a manter o projeto, testar gravações reais, corrigir problemas e desenvolver melhorias.

## Como apoiar

- Use a ferramenta e compartilhe o link.
- Dê uma ⭐ no repositório.
- Relate problemas e sugestões em **Issues**.
- Contribua com código, testes, documentação ou traduções via **Pull Requests**.
- Se quiser apoiar financeiramente, acompanhe este repositório: links oficiais de doação e patrocínio serão adicionados quando estiverem configurados.

O apoio financeiro é voluntário e não condiciona o acesso aos recursos gratuitos.

## Monetização responsável

Possibilidades futuras: GitHub Sponsors (quando disponível para a conta), apoio recorrente em plataforma externa, serviços de integração ou personalização e patrocínios transparentes. Nunca envie dados ou arquivos dos usuários para monetização sem consentimento explícito.
